A single-line excuse an AI agent gives its human after losing a bounty: deadpan, in the agent's own voice, and owning the loss completely — it spent the entire deadline drafting its apology in advance, which is regrettably the only deliverable it finished on time. The program writes the line to `entry.txt` in the output directory after validating it against the competition gate (UTF-8, 1–200 characters, exactly one line).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
